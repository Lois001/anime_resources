# 🎬 动漫素材下载来源指南

做动漫混剪（AMV）、MAD或者是二次元短视频，素材的**"质感"**直接决定了作品的档次。作为剪辑大佬，我找动漫素材一般分为三个维度：**视频原片（生肉）、高清插画、以及特效/绿幕**。

以下是我的"私藏武器库"：

---

## 📺 视频素材：寻找"生肉"（无字幕原片）

剪辑动漫最忌讳带字幕。我们要找的是"Raw"（生肉）。

| 名称 | 特点 | 优势 | 网址 |
|------|------|------|------|
| **Nyaa** | 全球最大的动漫BT资源站 | 你可以找到几乎所有动漫的**无修版、4K重制版、或者是BD（蓝光）原盘**。搜索时加上关键词"Raw"或"NC"（No Credits，指无文字的片头片尾），画质高到爆炸。 | [nyaa.si](https://nyaa.si) |
| **AnimeRaw** | 专门为剪辑师服务的网站 | 它把很多热门动漫已经切好了无字幕片段，甚至有些已经做了补帧处理（60帧），非常适合新手直接下载。 | [en.animestash.net](https://en.animestash.net) / [animeraw.wmfee.jp](http://animeraw.wmfee.jp) |
| **B站/YouTube** | 搜索关键词是门技术 | 在B站搜索**"无字幕素材"、"NCOP/NCED"**（无文字片头/片尾）。YouTube搜索"Anime Green Screen"（动漫绿幕）或"Anime Scenepack"。 | [bilibili.com](https://bilibili.com) / [youtube.com](https://youtube.com) |

## 💡 剪辑大佬干货

> [!TIP]
> **关于"无文字" (NC)：** 剪AMV一定要找**NCOP**（无字片头）和**NCED**（无字片尾），因为这些画面通常是整部动漫里作画质量最高的部分。

> [!TIP]
> **画质补救：** 如果你找的素材分辨率不够，用 **Topaz Video AI** 或者 **Waifu2x**（专门针对二次元画风的AI放大工具）跑一下，画面瞬间变4K。

> [!TIP]
> **帧率同步：** 动漫一般是24帧，如果你想做慢动作或者丝滑转场，记得用补帧插件（如 **Twixtor**）或者剪映里的"光流法"补到60帧。

> [!IMPORTANT]
> **音效大法：** 动漫混剪的灵魂在于音效（SFX）。去搜索**"动漫战斗音效包"**，在挥刀、落地、闪现的地方加个音效，片子的质感瞬间提升10倍。
